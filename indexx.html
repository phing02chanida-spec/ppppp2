คู่มือการเอาไฟล์แดชบอร์ดขึ้น GitHub Pages

คุณสามารถเปิดใช้แดชบอร์ดนี้เป็นเว็บไซต์ออนไลน์ให้ทีมงานเข้าดูได้ฟรี 24 ชม. ผ่าน GitHub Pages ด้วยขั้นตอนง่ายๆ ดังนี้:

  1. เซฟไฟล์นี้: บันทึกซอร์สโค้ดไฟล์นี้ ตั้งชื่อว่า index.html
  2. สมัคร/เข้าสู่ระบบ GitHub: ไปที่ github.com
  3. สร้าง Repository ใหม่: กดปุ่ม + แล้วเลือก New repository
  4. อัปโหลดไฟล์: ตั้งชื่อ Repo (เช่น health-dashboard) แล้วเลือก Upload an existing file ลากไฟล์ index.html ลงไป แล้วกด Commit changes
  5. เปิดใช้งาน GitHub Pages: ไปที่แท็บ Settings → เมนูด้านซ้ายเลือก Pages → ในส่วน Branch ให้เลือก main (หรือ master) แล้วกด Save
  6. เรียบร้อย! รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น https://your-username.github.io/health-dashboard/ สามารถส่งให้ผู้บริหารหรือทีมงานเข้าดูข้อมูล Real-time ได้ทันที!

หมายเหตุสำหรับการอัปเดตข้อมูล:

เมื่อมีผู้กรอกข้อมูลเพิ่มใน Google Sheet คุณไม่จำเป็นต้องแก้ไขโค้ดใดๆ อีก แดชบอร์ดจะทำการดึงข้อมูลใหม่มาแสดงบนเว็บโดยอัตโนมัติตามเวลาที่กำหนด
